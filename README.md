# ⚡ Wattogether

A frontend web project that visualizes a peer-to-peer renewable energy trading platform, where users can understand how surplus solar energy can be shared within communities.

🔗 Live Demo: https://ankidharmani-tech.github.io/whats-up/home.html

✨ Features

Interactive energy trading dashboard

Stats for energy traded, value generated & CO₂ saved

Clean, responsive UI

Concept inspired by decentralized energy networks
